# Simple Restaurant System Java

A simple restaurant ordering application developed using Java.

## Features

- Display restaurant menu
- Food and beverage categories
- Maximum 4 orders
- Calculate subtotal
- Discount 10% for orders above Rp100.000
- Buy one get one beverage promotion
- Tax calculation 10%
- Service fee Rp20.000
- Print payment receipt

## Technologies

- Java
- Object Oriented Programming
- Array
- Switch Case
- If Else Decision Structure
